# 📺 AU TVBox Sources - 专为澳洲优化的极速影视源

专为身在澳洲（海外）的 TVBox / FongMi / 影视仓 用户打造的自动化影视源清洗与聚合系统。由 GitHub Actions 每日自动巡检、测速并更新。

---

## 🌟 核心特性

- 🚫 **彻底剔除磁力 / BT / P2P**：坚决不收录磁力链接，彻底规避澳洲 ISP 版权警告与冷门找种慢问题。
- 🚫 **彻底剔除网盘搜片**：不依赖阿里/夸克/百度网盘，免去国内扫码登录与海外限速困扰。
- 🚫 **剔除非影视冗余**：清理掉所有小学/初中/高中课堂、儿童启蒙、戏曲、Tg引流等无关站点。
- ⚡ **澳洲本地直连秒播**：仅收录在海外直连顺畅、真实分辨率 $\ge$ 1080P/4K 的纯直链切片大厂站。
- 🛡️ **内置切片去广告规则**：内置 15 条针对索尼、量非、快看等采集站的 m3u8 广告切片过滤规则。
- 🤖 **全自动云端维护**：由 GitHub Actions 每天两次自动巡检，剔除死链，更新站点。

---

## 🚀 电视端配置地址

在 **影视仓** 或 **FongMi** 的【设置】→【配置地址】中，直接填入以下多仓订阅链接：

```text
https://<你的GitHub用户名>.github.io/<仓库名>/multi.json
```

---

## 📂 多仓架构说明

订阅链接内包含以下 3 个分层仓库：

1. **🚀 澳洲极速主力仓 (`fast.json`)**
   - 包含 8 大核心秒播站（厂长影视、金牌影视、农民影视、瓜子影视、火火影视、360官源、立播秒播、光影不卡）。
   - 全局搜索 1 秒出结果，日常追剧首选。
2. **🎬 1080P超清精选仓 (`hd.json`)**
   - 包含主力大站 + 咕咕动漫 + 看球直播（体育赛事） + 瓜子体育。
3. **🛡️ 全网冷门兜底仓 (`backup.json`)**
   - 包含 40+ 个存活的纯直链切片站，用于搜索冷门老剧。
